### **Тестовое задание для Союз-Прибор**

##### Общие сведения
Реализован сервис автоматизированного написания черновика карточки товара(Контрольно-измерительного прибора) по ключевым характеристикам.
Для работы сервиса может быть использован любой ИИ-провайдер, API которого реализует Open AI Chat Completion API протокол.

##### Реализация проекта
Сервис написан на Python при помощи фреймворка FastAPI. Код разделён на infrastructure и presentation слои. infrastructure слой содержит реализацию ИИ-клиента, presentation реализует обработчики и их работу. Сервис обрабатывает возможные ошибки при работе со сторонним API, а также валидирует входные данные от пользователя.

##### Принятые решения и ошибки
Основные решения и ошибки ассоциируются с системным промптом. Модель постоянно выдумывала данные основываясь на общих знаниях, напримен, про монометры, либо выдумывала характеристики из остальных данных, например, часто добавляла в характеристики Тип: показывающий. Решилось это подбором правил, например, 1 ключ в спеках - 1 характеристика, такие численные ограничения действуют лучше, чем промпт "не выдумывай характеристики". Так же модель часто додумывала функционал магазина, например, возможность продажи в опт или в розницу. По коду особых ошибок не было, изначально было принято решение написать менеджера ИИ клиентов, разделяющего ИИ клиентов по ip пользователя и хранящего историю чата, но позже это решение было изменено в сторону одного клиента без истории чата по причине возникновения галюцинаций модели из-за истории чата.

##### Запуск и тестирование
1. Откройте терминал по адресу папки рабочего каталога
2. Выполните `uv sync --no-dev` для скачивания зависимостей
3. Выполните `uv run fastapi dev src/main.py` для запуска проекта
4. В браузере откройте http://127.0.0.1:8000/docs
5. Выполните POST-запрос с помощью нажатия Try it out -> отредактируйте входной JSON -> Execute
6. Ожидайте ответа от ИИ-провайдера

Присоединение выполнено с резьбой G1/2, этот параметр определяет совместимость прибора с отборным устройством в точке измерения.

Показывающие манометры с диапазоном до 1,6 МПа применяются для контроля давления в трубопроводных системах, гидравлических и пневматических линиях, насосных и компрессорных установках, а также в технологических контурах, где показания снимаются непосредственно по месту эксплуатации.

Типовые задачи: наблюдение за рабочим давлением в трубопроводных и гидравлических системах, контроль режимов насосного и компрессорного оборудования, отслеживание отклонений давления в технологических контурах, где рабочее давление не превышает 1,6 МПа. Ключевые параметры для быстрого сопоставления с требованиями заказчика: диапазон 0-1,6 МПа, класс точности 1,5, диаметр корпуса 100 мм, присоединение G1/2.

Данных в карточке недостаточно для ответов на частые вопросы заказчика. Стоит уточнить у поставщика: расположение присоединения (радиальное или осевое), измеряемую среду и ее совместимость с прибором, температурные ограничения эксплуатации, материал корпуса, наличие демпфирования или жидкостного заполнения, комплектацию, массу, сведения о поверке и сертификации, а также полный текст описания производителя.

Обратите внимание: описание товара в исходных данных выглядит обрезанным (текст приведен не полностью), поэтому сведения о назначении ограничены фразой об измерении избыточного давления.

Мультиметры такого типа применяют электромонтажники, радиолюбители и сервисные специалисты для быстрой проверки состояния цепей и электронных компонентов.

Прибор подойдёт электромонтажникам, радиолюбителям, сервисным и домашним мастерам, которым нужен простой цифровой мультиметр для повседневных измерений. Основные задачи: проверка наличия и величины постоянного и переменного напряжения, измерение постоянного тока до 10 А, оценка сопротивления элементов и цепей, в том числе косвенная проверка целостности проводки по сопротивлению. Диапазоны до 1000 В и до 750 В позволяют работать с сетевыми цепями, питание от батареи «Крона» делает прибор мобильным.

Данных о товаре немного, и перед консультацией стоит уточнить у поставщика: точность (погрешность) измерений, наличие режимов прозвонки со звуковой индикацией, проверки диодов и транзисторов, защиту входов и предохранитель, габариты, массу, рабочую температуру и комплектацию, включая наличие щупов.
